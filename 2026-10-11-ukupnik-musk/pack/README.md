# Пак дисциплины «Теорема Укупника-Маска»

Скиллы, которые задают входной гейт перед началом работы. Не методология процесса,
а фильтр решения: шесть вопросов до первой строки кода, до первой правки, до
первой публикации.

Мотивирующий документ пака: [THEOREM.md](THEOREM.md).

## Что внутри

| Скилл | Роль | Когда загружать |
|---|---|---|
| `ramsey` | Прожарка артефакта перед выдачей: атаки на документ, минимальные фиксы, PRISM-проход | Отчёт, статья, инструкция, которые уходят наружу |
| `plan-then-do` | План с bite-sized шагами и обязательной секцией входного гейта | Любая работа на несколько шагов |
| `pstack-principles` | 21 принцип проектирования, ревью и отладки в таблице «ситуация → принцип» | Выбор подхода к коду |
| `research-before-build` | Prior art до тулинга: два существующих решения, описание механизма | Новый инструмент, скрипт, коннектор, обходчик |
| `agent-skills-interview-me` | Что заказчик хочет на самом деле, отделение want от should-want | Недоопределённая задача, перед планом |
| `agent-skills-doubt-driven-development` | Адверсариал в свежем контексте, смещённый опровергнуть | Нетривиальное решение перед тем, как оно встанет |
| `agent-workflow-gates` | Гейт как permission check, а не предложение в прозе | Любой процесс, который должен пережить сессию |
| `corporate-tool-workarounds` | Грабли Windows, MSYS, SSH, нативных путей, квотинга, BOM | Работа с инструментарием на границе оболочек |

## Порядок применения

Шесть осей из [THEOREM.md](THEOREM.md), затем вызов скиллов по строке работы:

```
1. Боцман   → на какой результат рассчитывает заказчик
2. Художник → кто уже решил это (research-before-build)
3. Маск     → что удалить прежде чем настраивать (pstack-principles)
4. Ли       → чем решать: скрипт, линтер, модель, субагент
5. Фома     → какое утверждение проверено пробой, а не взято на веру
6. Фейнман  → где результат мог быть подогнан под красивую теорию
```

Затем:

| Работа | Скилл |
|---|---|
| План, декомпозиция, шаги | `plan-then-do` |
| Артефакт наружу: отчёт, статья, документ, письмо | `ramsey` |
| Новый инструмент или скрипт | `research-before-build` |

Не цепочка подряд, только строки под работу. Письмо коллеге берёт `ramsey`; чинить
баг в своём коде не берёт ничего.

## Границы

Шесть осей это фильтр входящего решения, а не обряд. Порог входа решается ценой
ошибки:

- Необратимое или дорогое (прод, контракт, чужие деньги, публикация) проходит все
  шесть осей и артефакт идёт через `ramsey`.
- Обратимое и дешёвое делается сразу, с допущением, которое записано одной строкой.

## Установка

Скиллы Hermes загружаются из директории `skills/` активного профиля или из
`skills.create_dir` конфига. Скопировать папки отсюда туда и перезагрузить скиллы.

```bash
cp -r skills/* <hermes-home>/skills/
```

Каждый скилл самодостаточен, кроме `ramsey`, который роутит в остальные по имени.
`corporate-tool-workarounds` содержит `references/`, его надо копировать вместе.
