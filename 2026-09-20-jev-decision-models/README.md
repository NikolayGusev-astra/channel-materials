# Jev vs открытые модели решений: код и данные эвалов

Материалы к серии статей (часть 1 - пост 239, часть 2 - пост 240, часть 3 - открытые альтернативы).

## Что здесь

- `jev_client.py` - клиент TypeSafe Jev (System One): jev_ask / jev_batch / jev_triage, ретраи, пин версии.
- `laya_eisenhower.py` - матрица Эйзенхауэра на открытой модели laya (Apache 2.0): два noul на элемент, 4 квадранта + зона "спросить человека", Platt-калибровка, ECE.
- `run_evals.py` - воспроизведение эвалов: инъекции, реранкер, почта.
- `evals/` - сеты: 10 инъекций + 10 чистых текстов, 6+6 для реранкера, 25 заголовков, 15 писем с метками Jev (анонимизировано: тема/домен/вердикт).

## Запуск

```bash
pip install laya            # открытая модель, крутится на CPU
export TYPESAFE_API_KEY=... # только для Jev-частей

python run_evals.py B_jev   # инъекции через Jev API
python run_evals.py B_laya  # инъекции через laya локально
python run_evals.py E       # матрица на письмах
```
