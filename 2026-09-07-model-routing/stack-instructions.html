Свежая сессия. Новые MCP-серверы (chrome-devtools, headroom) видны только после рестарта сессии. Текущая сессия их не видит — это нормально.

Шесть инструментов

chrome-devtools-mcp
инспекция живого Chrome · 26 тулов
  • Консоль с source-mapped стеками, network, снапшоты DOM, скриншоты, perf-трейсы
  • Тулы появляются в сессии автоматически: take_snapshot, list_console_messages, network_requests…
  • Телеметрия Google отключена: --no-usage-statistics
Не навешивать на профиль с личными сессиями то, что не хочешь светить агенту.
headroom
сжатие контекста · CLI + MCP
  • headroom_compress → жмёт лог/JSON (60–95% на JSON), отдаёт хеш
  • headroom_retrieve — оригинал по хешу; headroom_stats — экономия
  • Типовой проход: длинный лог → compress → reasoning по сжатому
hermes mcp test headroom может дать ложный «Connection closed» — сервер жив, проверять прямым stdio-прогоном.
graphify
кодбаза → граф знаний
  • Код-парсинг tree-sitter локально; семантика — через LM Studio :1234, бесплатно
  • graphify <repo> --yes --backend openai с env (ниже)
  • graphify query "auth flow" --graph graphify-out/graph.json
Обязательный env: OLLAMA_HOST=127.0.0.1:11434 + OPENAI_BASE_URL=http://127.0.0.1:1234/v1 OPENAI_API_KEY=lm-studio. Глобальный OLLAMA_HOST=0.0.0.0 ломает запуск.
agent-browser
второй браузерный стек · Rust CLI
  • agent-browser open <url> / text / snapshot — 0.2–0.8s
  • Захват логинов: --auto-connect state save auth.json → работать через --state auth.json
  • network requests, trace start/stop, batch с --bail
ВСЕГДА export NO_PROXY="127.0.0.1,localhost" — иначе системный прокси вешает localhost-CDP. Деление: встроенный browser_exec — сессия; agent-browser — CLI, пакеты, auth, трейсы.

model-routing
автовыбор модели · экономия лимитов
  • Скоринг запроса (11 сигналов) → категория → цепочка из 3 звеньев
  • Звенья диверсифицируют провайдеров: zcode → codex → free
  • Правила и диаграмма — ниже
Спросить «какой моделью делать» или «usage limit что делать» — роутер сработает. Твоё явное «сделай на sol» перекрывает скоринг.

Железные правила переключения

codex «usage limit» — кап аккаунта: все 3 модели падают разом. Прыжок на zcode/free, не на соседнюю модель codex.
429 на free-модели — следующее звено цепочки, не ретрай той же. Ретрай — только после сброса окна.
≤ 2 звена подряд у одного провайдера. luna → terra ок; luna → terra → sol при капе бессмысленно.
Free-звенья: интерактив — последними (медленно); writing/batch — первыми (экономия главнее).

Грабли, на которые я уже наступил

  • hermes mcp add пишет --connect-timeout в args сервера — после регистрации проверить блок в config.yaml руками
  • hermes mcp test даёт ложный «Connection closed» на живом сервере — валидировать venv-клиентом mcp или прямым stdio-прогоном
  • Прокси vs localhost: всё, что ходит на 127.0.0.1 (CDP 9223, LM Studio 1234), требует NO_PROXY=127.0.0.1,localhost
  • OLLAMA_HOST=0.0.0.0 (глобальная env) валит graphify — переопределять точечно на 127.0.0.1
  • graphify + ollama-бэкенд требует extra graphifyy[ollama]; рабочий путь — --backend openai на LM Studio
