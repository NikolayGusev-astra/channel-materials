# Model-Routing skill

Скилл автовыбора модели для AI-агента: детерминированный скоринг сложности запроса,
6 категорий, цепочки из 3 fallback-звеньев с диверсификацией провайдеров.

## Установка

Скопировать в каталог скиллов Hermes:

    cp SKILL.md ~/AppData/Local/hermes/skills/dev/model-routing/SKILL.md   # Windows
    cp SKILL.md ~/.hermes/skills/dev/model-routing/SKILL.md               # Linux/macOS

Новая сессия подхватит скилл автоматически.

## Что внутри

- Таблица из 11 сигналов сложности с весами (детерминированный подсчёт, без LLM)
- Пороги категорий: quick / standard / deep / architect / writing / ultrabrain
- Цепочки по 3 звена: правило диверсификации провайдеров (лимиты per-provider)
- Правила переключения: codex account-cap, 429-fallback, лимит 2 звена подряд
- Формат лога маршрутов (JSONL) для недельной статистики расходов

## Адаптация под свой инвентарь

Три таблицы правятся под свой стек: провайдеры (раздел 1), пороги (раздел 2),
цепочки (раздел 3). Подробнее - статья в родительском каталоге.
