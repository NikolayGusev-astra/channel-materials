# Материалы к статье «Как разбираться в ответах ИИ»

Собирает то, что упоминается в тексте, чтобы статья была проверяемой.

```
article.md                        текст статьи
materials/teachme-bundle/         отчуждаемая копия скилов диспетчера teachme
materials/scripts/setup-latex.sh  установка LaTeX для роликов Manim с нуля
```

## teachme-bundle

29 папок со `SKILL.md`, 8 МБ, симлинки разыменованы - копия переносится на
другую машину целиком. Состав и развёртывание описаны в
`teachme-bundle/README.md`, там же раздел про то, какие три скила упираются
в отсутствующее окружение.

## setup-latex.sh

Ставит MiKTeX в portable-режиме и сразу переводит вопрос об установке
недостающих пакетов в автоматический режим, иначе агент зависнет на диалоге.

```bash
bash materials/scripts/setup-latex.sh
```

Скрипт идемпотентен: если `pdflatex` уже в PATH, установка пропускается и
остаётся только проверка. Финальный шаг - штатный `manim checkhealth`,
ожидаются четыре строки PASSED.
