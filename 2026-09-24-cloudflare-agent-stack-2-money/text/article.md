# Cloudflare для агентов, часть 2: у агента появились деньги

Агент без платёжного инструмента - стажёр без корпоративной карты: всё интересное упирается в "попроси человека". Cloudflare строит финансовый слой агентного веба с двух сторон: как агенты платят и как сайты берут плату.

## Проблема: у агента нет ни имени, ни кошелька

Чтобы попробовать новое API, агенту нужно зарегистрироваться, а для этого - иметь устойчивый идентификатор и способ оплаты. Сегодня оба шага идут через человека: логин придумывает он, карту привязывает он, ключ генерирует он. Машинно-машинная экономика на этом не разгоняется.

Ответ - Cloudflare Wallets. Двухуровневая схема: Account Wallet принадлежит человеку и хранит средства, Virtual Wallet выдаётся агенту и работает по API-ключу с гардрейлами - лимит суммы, белый список получателей, максимальный размер одной транзакции. Агент autonomo тратит в рамках разрешения, человек не утверждает каждый чих. Пока жива только резервация хендла cloudflare.pay - фондирование и API обещают "в ближайшие месяцы". Параллельно открыли Stripe Projects - делегированную оплату картой, мост для тех, кому кошельки ждут.

## x402: HTTP, который умеет брать деньги

Протокол реанимирует код ответа 402 Payment Required, 30 лет пролежавший в стандарте без работы. Сайт отвечает 402 с ценой и получателем, клиент повторяет запрос с платёжным заголовком, фасилитатор проводит транзакцию в USDC, сайт отдаёт контент. Без аккаунтов, подписок и API-ключей.

Cloudflare называет цифру: больше миллиарда 402-ответов в день уходит ботам и краулерам на сайтах сети - спрос на стандарт есть, не хватало формата. CF с Coinbase учредили x402 Foundation, предложили схему отложенного расчёта для краулеров: работаешь день, аудит-лог копишь, платишь одной транзакцией вечером. Знакомая любому бухгалтеру модель, и это комплимент: финансовая инфраструктура для машин придумана по лекалам человеческой.

## Monetization Gateway: sell-side

Вторая сторона рынка. Владелец сайта или API хочет брать плату с агентных клиентов, но не хочет писать биллинг. Monetization Gateway делает это на edge: платёжные стратегии исполняются до того, как запрос долетит до origin-сервера. Страницы, датасеты, API, MCP-тулзы - всё продаётся за микроплатежи меньше цента, экономика сходится даже на одном запросе, потому что агент не покупает подписку - он покупает один вызов.

Waitlist открыт со 2 июля 2026. Это самая важная деталь статуса: продукт анонсирован, но купить его нельзя - как и Wallets, это ставка на полгода вперёд, не инструмент на сегодня.

## NET Dollar: зачем CF стейблкоин

Анонс собственного стейблкоина вышел 25 сентября 2025 и вызвал вопросы "зачем, есть же USDC". Ответ лежит в связке: когда миллиарды микроплатежей по центу идут через твою сеть, каждая транзакция с чужой комиссией - это налог на собственный Monetization Gateway. Свой стейблкоин - это вертикальная интеграция платёжного слоя. Пока в проде всё равно USDC, NET Dollar - заявка на будущее.

## Складываем картину

Веб, где агент с кошельком находит платный API, платит цент за вызов, а сайт получает деньги без биллинг-команды - уже не футурология, а архитектура, большая часть которой написана. Не хватает главного: фондирования кошельков и общего запуска Monetization Gateway. Обещаны "в ближайшие месяцы" - следим.

В третьей части - периметр: как сайты решают, пускать ли агента, и почта, которую агент наконец умеет читать.
