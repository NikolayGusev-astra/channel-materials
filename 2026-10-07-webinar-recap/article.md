# Вебинар «Hermes как личный инструмент»: запись, материалы и ответы на вопросы из чата

Сложность: низкая

7 октября я провёл вебинар для RebrainMe: «Hermes как личный инструмент: скиллы и локальные пайплайны за 0 рублей». 75 анкет обратной связи, средняя оценка 4,9 из 5, 96% зрителей заявили, что придут ещё. Отзывы я уже публиковал в канале, включая мою любимую: «Ожидал практики, а получил "мистера тараторку"». Справедливо: локальный пайплайн выдаёт 30 токенов в секунду, я в разговоре заметно быстрее.

Здесь то, что обещал после эфира: запись, презентация, разбор вопросов из чата, на которые не успел ответить, и джентльменский набор скиллов, о котором спрашивали в эфире дважды.

## Вопросы из чата, выпуск 1

В эфире ответили не на всё. Три вопроса закрыл письменно, остальные забрал в программу ноябрьского интенсива: они про практику, а практика заслуживает демо, а не абзаца текста.

### Как искать скиллы

Три пути. Первый, Skills Hub, каталог, встроенный в Hermes:

```
hermes skills search docker        # поиск по всем реестрам
hermes skills browse               # каталог целиком, с пагинацией
hermes skills inspect <id>         # превью SKILL.md без установки
hermes skills install <id>         # установка
hermes skills list                 # что стоит в профиле
```

В хабе больше 100 тысяч скиллов из десятка с лишним реестров. Фильтр по источнику отсекает шум: `hermes skills search terraform --source official` ищет только по официальным скиллам.

Второй путь, статья про устройство скиллов: https://hermes-agent.ru/news/explain-skills-ladder/

Третий, проверенный список из репозитория материалов, о нём ниже.

### Диспетчер скиллов самописный?

Нет. Диспетчер это встроенная механика Hermes: описание скилла лежит в SKILL.md с frontmatter, где указано имя и когда скилл применять. Агент читает описания и сам решает, что загрузить под задачу. Внешнего роутера нет.

Самописным бывает другое: сами скиллы. Вендорский знает доку продукта, ваш личный знает ваши конвенции, ваши гейты и ваши грабли. Вторые со временем ценнее первых.

### MCP или tools: когда что

Tools уже внутри агента: файлы, терминал, браузер, поиск, память. MCP это протокол подключения внешнего: Jira, Confluence, базы, корпоративные API. Правило из трёх строк. Решается локально: tools. Нужен внешний API: готовый MCP-сервер. Готового нет: пишите свой, это пара сотен строк.

Нюанс из практики: каждый подключённый тул ест токены даже когда не используется. Подключайте только то, что нужно задаче, а тулы MCP-сервера в Hermes можно фильтровать.

## Джентльменский набор скиллов

Правило отбора: берём official от Nous Research и скиллы, написанные самим вендором продукта. У вендора ответственность за актуальность, у клона из skills.sh её нет.

От Nous Research:

- docker-management: контейнеры, образы, тома, Compose;
- watchers: поллинг RSS, JSON и страниц по расписанию;
- pinggy-tunnel: SSH-туннели без белого IP;
- hermes-s6-container-supervision: s6-сервисы внутри Docker-образа Hermes.

От Docker Inc (репозиторий github.com/docker/skills ведут инженеры Docker):

- docker-project-foundations: структура контейнеризуемого проекта;
- docker-build-strategies: сборки, слои, кэш, multi-stage;
- docker-compose-patterns: многоконтейнерные стеки;
- docker-sandboxes-lifecycle: изолированные microVM-песочницы для запуска агентов.

От Cloudflare:

- cloudflare-deploy: консолидированный скилл по всей платформе из кураторского репозитория openai/skills. Workers, Pages, Durable Objects, деплой через Wrangler;
- cloudflare-temporary-deploy: Worker без аккаунта через wrangler --temporary;
- publish-site: версионированные деплои на GitHub Pages и Cloudflare Pages.

Команды установки для всех лежат в репозитории материалов, файл vendor-skills.md.

Честный ответ на вопрос «а что ещё вендорского есть»: искал по официальному источнику отдельно terraform, ansible, kubernetes, prometheus, grafana, nginx, github actions. Ноль результатов. По этим темам в хабе только community-скиллы лотерейного качества. Если работа с ними повседневная, честнее написать свой скилл под свои конвенции. В этом и идея скиллов: процедурная память под свою практику, а не чужой пересказ документации.

## Что в ноябре

Вопросы из чата ушли в программу интенсива: сканы счёт-фактур без додуманных цифр, колл-центр на Hermes, батчинг локальных моделей, сравнение с OpenCode и DeepSeek Harness, что тянет Xeon без GPU, какие 20 моделей из демо и откуда, живой пайплайн на простом примере.

«Зовите его ещё раз» сработало быстрее, чем я ожидал. В ноябре будет продолжение и интенсив с практикой и проверкой заданий.
