# ТЗ: статья "YandexGPT-5-Lite-8B как RAG-ответчик"

1. Этот файл ТЗ
2. test-results.json - РЕАЛЬНЫЕ результаты 8 живых тестов (источник всех цифр, ничего не выдумывать)
3. pipeline-snippets.md - проверенный рабочий код пайплайнов (сниппеты брать отсюда)

## Что за статья
Практическая статья для Telegram-канала @hermesagentru (аудитория: инженеры, DevOps).
Тема: зачем нужен instruct-генератор поверх RAG/поиска и как подключить YandexGPT-5-Lite-8B-instruct.

## Тезис (6-10 слов)
"Маленький генератор с честным отказом - рабочая лошадь RAG"

## Структура
1. Крючок: у всех есть поиск/RAG, но выдача - это список чанков. Кто превратит их в ответ?
2. Роль генератора в пайплайне: retrieval находит, генератор отвечает. Почему instruct-модель, а не base.
3. Почему YandexGPT-5-Lite-8B: 8B Q4_K_M = 4.6GB (влезает в 8GB VRAM целиком), ~29 tok/s, русский сильный, официальный GGUF, 32k контекст. НЕ путать с новой линейкой AliceAI (Foundation 80B - серверная, ~45GB Q4).
4. Пайплайн 1: RAG-ответчик (retrieval → контекст с номерами источников → ответ с цитатами). Код из pipeline-snippets.md.
5. Пайплайн 2: ответчик над поисковой выдачей (web_search → сниппеты → ответ). Код.
6. ГЛАВНОЕ: тесты на честность (8 тестов из test-results.json) - модель ОТКАЗЫВАЕТСЯ отвечать, когда в контексте нет ответа. Это фича, не баг: RAG-генератор, который выдумывает, хуже, чем нет генератора. Таблица результатов.
7. Подводные камни: корпоративный прокси перехватывает localhost:1234 (502) - пустой ProxyHandler; нестандартный темплейт Ассистент:[SEP] - через OpenAI-compat LM Studio обёрнуто автоматически; лицензия - коммерческое до 10M исходящих токенов/мес.
8. Итог: для чего годится (внутренние базы знаний, персональный perplexity, ответчик в чат-боте), для чего нет (агентный tool-use, мульти-шаговое планирование - это к большим моделям).

## Жёсткие правила
- От первого лица, инженерный живой тон, самоирония уместна
- Цифры ТОЛЬКО из test-results.json и pipeline-snippets.md. Ничего не выдумывать.
- 0 эм-дашей (U+2014), 0 ёлочек («»), 0 CJK. Проверка: t.count(chr(0x2014))==0
- Код-сниппеты: из pipeline-snippets.md, можно сокращать, но не менять смысл
- 2-5 ссылок: HF модель, HF GGUF, LM Studio
- Обфускация: никаких реальных доменов компании, хостов, IP. "локальный RAG на корпоративной вики" вместо названий. lodestone/astralinux НЕ упоминать.
- Без буллетов-маркеров в финальном посте, но статья для Telegra.ph - можно списки
- Сложность: средняя
- Объём: 8-12K символов
- Никаких "стоит отметить", "показательно", "важно понимать"
- Русский: без калек ("латенс" нет, "задержка" да), ИТ-термины ок (RAG, эмбеддинг, промпт)
