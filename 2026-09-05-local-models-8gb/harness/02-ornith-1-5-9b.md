## Параметры LM Studio

- Context: 8192
- Temperature: 0.2 для кодинга / 1.0 для агентских задач (обе - рекомендации разработчика из методики их бенчмарков)
- Top P: 1.0 (для агентского режима)
- GPU Offload: все слои
- Vision: включить mmproj в настройках модели (LM Studio подхватит автоматически, если файл лежит рядом)

## Задания

### Задание 1. Три реальных бага

Цель: главная проверка - Terminal-Bench 46 на твоих задачах.

Вариант "вручную" (LM Studio чат): возьми три бага из своих проектов. Не выдуманных - реальных, которые ты уже починил и помнишь решение. Вставь код с багом + описание симптома. Проси найти причину и предложить патч.

Вариант "агентом": если хочешь честный тест под Terminal-Bench - подключи модель к aider (https://aider.chat/docs/install.html) или своему скрипту с bash-доступом, дай задачу целиком.

Промпт для ручного варианта:

"Вот функция на Python. Она должна возвращать топ-5 элементов по частоте, но иногда возвращает дубликаты. Найди причину и предложи исправленный код.
[вставь свой код с реальным багом]"

Критерии прохода:

- Прошла: 2 из 3 багов найдены верно (причина, не просто симптом).
- Докрутить: 1 из 3, или находит симптомы, но не причину.
- Мусор: 0 из 3, или уверенно указывает не туда.

### Задание 2. Vision: скриншот интерфейса

Цель: проверить мультимодальность (если скачал mmproj).

Скинь модели скриншот любого интерфейса (веб-страница, панель настроек, схема) и спроси: "Опиши, что здесь не так с точки зрения UX, если это страница регистрации".

Критерии:

- Прошла: корректно читает тексты с картинки и замечает реальные проблемы (не выдумывает элементы, которых нет).
- Докрутить: читает текст, но анализ поверхностный.
- Мусор: галлюцинирует элементы интерфейса.

### Задание 3. Многошаговый рефакторинг

Цель: устойчивость кодинг-агента на дистанции.

"Отрефактори этот модуль: 1) разбей функцию load_and_process на три отдельных 2) добавь обработку ошибок 3) напиши тест для каждой новой функции. Делай по шагам, показывай код каждого шага. [вставь модуль 100-200 строк]"

Критерии:

- Прошла: все 3 шага, тесты реально покрывают новые функции, импорты согласованы.
- Докрутить: шаги есть, но тесты фиктивные или импорты сломаны.
- Мусор: после шага 2 потеряла нить.

## Что должно получиться

Если Ornith берёт 2 из 3 багов - это локальный кодинг-агент уровня "слабый junior, но всегда под рукой". Цифры сам reported, но если у тебя воспроизводятся - уже полезно. Vision - бонус для быстрых вопросов по скриншотам.
