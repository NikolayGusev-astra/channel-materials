# Мини-харнесс: 6 локальных моделей под 8 GB VRAM

Папка содержит всё для вечернего теста: по файлу на модель - ссылки на Hugging Face, параметры запуска в LM Studio и задания с критериями прохода.

Железо: любая карта с 8 GB VRAM (RTX 3060 Ti / 4060 и т.п.).

Порядок работы с каждой моделью:

1. Скачай файл(ы) кванта по ссылке из карточки модели (VLM-моделям нужен ещё mmproj-файл).
2. Загрузи в LM Studio (вкладка My Models -> перетащи файл или укажи папку).
3. Выстави параметры из карточки ( вкладка настройки чата -> Advanced / Sampling).
4. Прогони задания. Записывай вердикт сразу: модель / задание / годно-докрутить-мусор / токенов в секунду.

Общие правила для честного сравнения:

- Один и тот же рантайм (LM Studio одного билда) для всех моделей.
- Контекст одинаковый (8192, если модель не требует больше).
- Температуру ставь по карточке модели - они разные, это часть модели, не "нечестность".
- Скорость меряй на генерации длиннее 200 токенов (первые токены всегда медленные).
